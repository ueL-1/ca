# 사용시간 관리 (Android)

요일별로 하루 최대 휴대폰 사용시간을 정하고, 한도를 넘으면 전화를 제외한 다른 앱 위에 "오늘 한도 초과" 화면을 띄우는 앱입니다.

## 설치

1. `dist/screentime-1.0.0.apk`를 휴대폰으로 받아 실행합니다. (Android 9 이상)
2. "출처를 알 수 없는 앱" 허용을 묻으면 허용합니다. Play 프로텍트 경고가 뜨면 "그래도 설치"를 누릅니다.
3. 앱의 **권한·설정** 탭에서 필수 권한 2개를 허용합니다.
   - 사용정보 접근
   - 다른 앱 위에 표시
4. 권장 권한(알림, 배터리 최적화 제외)도 허용하면 제한 기능이 꺼지지 않고 더 안정적으로 동작합니다.
5. 권한 화면에서 "제한된 설정" 안내가 뜨면 설정 › 애플리케이션 › 사용시간 관리 › ⋮ › **제한된 설정 허용** 후 다시 시도합니다.

> 오늘 이미 한도를 넘은 상태에서 권한을 켜면 바로 초과 화면이 뜹니다. 먼저 메인 탭에서 요일별 시간을 정한 뒤 권한을 켜세요.

## 동작 규칙

| 항목 | 규칙 |
|---|---|
| 사용시간 | 화면이 켜져 있고 잠금이 풀린 시간만 셉니다. **화면이 꺼져 있으면 앱이 실행 중이어도 세지 않습니다.** 전화·통화 화면·긴급전화 사용 시간과 초과 화면이 떠 있던 시간도 빼고 셉니다. |
| 기록 보관 | Android 시스템의 사용 기록에서 계산하므로 앱 종료·강제 종료·재부팅 후에도 유지됩니다. |
| 요일별 한도 | 시간·분(5분 단위)으로 설정하며, 바꾸면 바로 저장되고 계속 유지됩니다. 한도를 넘은 날에는 그 날 한도를 늘릴 수 없습니다(줄이기는 가능). |
| 한도 초과 | 전화 앱을 뺀 모든 앱(홈 화면·설정 포함) 위에 초과 화면을 띄웁니다. 화면이 꺼지거나 잠기면 숨기고, 잠금 해제하면 다시 띄웁니다. |
| 딱 10분! | 하루 1회, 실제 사용시간 기준 10분을 더 씁니다. 자정에 초기화됩니다. |
| 이번 주 제한 해제 | 주 1회, 이번 주 일요일 24:00까지 제한을 끕니다. 매주 월요일 00:00에 다시 쓸 수 있습니다. |
| 전화 | 초과 화면의 "전화 걸기", 통화 화면, 긴급전화는 막지 않습니다. 잠금화면의 긴급전화도 항상 쓸 수 있습니다. 전화 상태 권한을 허용하면 통화 중에는 초과 화면을 숨깁니다. |
| 재부팅 | 부팅이 끝나면 감시 서비스가 자동으로 다시 시작됩니다. |

## 한계

- 일반 앱은 Android가 다른 앱을 "정지"시키는 기능을 쓸 수 없습니다. 그래서 다른 앱 위에 화면을 덮는 방식으로 제한합니다.
- 알림창과 빠른 설정은 가릴 수 없습니다.
- 앱을 삭제하거나 안전 모드로 부팅하면 제한이 풀립니다.

## 빌드

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties   # platforms;android-36, build-tools 35/36
./gradlew testDebugUnitTest assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

Kotlin + Jetpack Compose, minSdk 28 / targetSdk 36.
